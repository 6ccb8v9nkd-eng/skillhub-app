SkillHub 6.2 — детализация ответов

Что нового:
- каждая новая попытка сохраняет выбранный сотрудником вариант по каждому вопросу;
- сохраняется правильный вариант и объяснение;
- работает для обычных/Hard-кейсов и живых диалогов;
- Наставник → Команда → История → Ответы;
- сотрудник в «Мой прогресс» также может раскрыть собственные ответы;
- старые попытки сохраняются, но для них детальных ответов нет, потому что версии до 6.2 их не записывали.

Порядок обновления существующего проекта:
1. Сначала выполнить SkillHub_6_2_SQL_ДЕТАЛИ_ОТВЕТОВ.sql в Supabase.
2. Затем загрузить файлы из SkillHub_6_2_ANSWER_DETAILS_UPDATE.zip в GitHub skillhub-app поверх старых.
3. Commit changes.
4. Подождать публикацию GitHub Pages и обновить SkillHub.
