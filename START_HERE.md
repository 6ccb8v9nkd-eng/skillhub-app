# SkillHub 6.0 Free — запуск без платного сервера

Эта версия работает по схеме:

**GitHub Pages (интерфейс/PWA) → Supabase Free (общая база и авторизация)**

Нет Docker, Render, Timeweb и постоянно работающего Python-сервера.

## Что уже есть

- мобильная тёмная PWA с иконкой;
- отдельные роли сотрудника и наставника;
- вход по корпоративному логину + личному PIN;
- первый профиль нового проекта автоматически становится наставником;
- наставник добавляет/отключает сотрудников и выдаёт код первого входа;
- Soft / Hard / выявление потребности / скорость печати;
- обычные кейсы, Hard-кейсы и живые пошаговые диалоги;
- ручное создание, изменение и удаление материалов;
- массовый импорт/экспорт Excel;
- черновик / публикация;
- доступ ALL или выбранным логинам;
- задания с дедлайном и минимальным результатом;
- результаты сотрудников и аналитика наставника;
- внутренние уведомления и автообновление через Supabase Realtime;
- офлайн-кэш интерфейса и ранее загруженных материалов.

## Один раз настроить

### 1. Создать проект Supabase
Создайте бесплатный проект на Supabase.

После создания откройте **SQL Editor → New query**. Скопируйте туда весь файл `schema.sql` и нажмите **Run**.

### 2. Отключить подтверждение e-mail
В Supabase откройте настройки Authentication / Email provider и отключите обязательное подтверждение e-mail (Confirm email).

SkillHub не использует реальную почту сотрудников: внутри Auth создаётся технический адрес на основе корпоративного логина.

### 3. Опубликовать интерфейс на GitHub Pages
Создайте НОВЫЙ репозиторий, например `skillhub-app`.

Важно: для бесплатного GitHub Pages репозиторий обычно делают Public. Пакет SkillHub 6.0 специально не содержит список ваших сотрудников, PIN, банковские кейсы или результаты. Не используйте старый `skillhub-pilot`, потому что в его истории уже были пилотные данные.

Загрузите в корень нового репозитория файлы из этой папки. Затем:

**Settings → Pages → Deploy from a branch → main → / (root) → Save**.

GitHub выдаст HTTPS-ссылку вида `https://USERNAME.github.io/skillhub-app/`.

### 4. Подключить общую базу
При первом открытии SkillHub попросит два значения Supabase:

- Project URL
- Anon / Publishable key

Они находятся в настройках/API вашего проекта Supabase. Вставьте их один раз и сохраните.

### 5. Создать наставника
На экране входа выберите **«Первый вход / создать PIN»**.

Введите свой корпоративный логин и придумайте PIN минимум 6 символов. В совершенно новом проекте код первого входа оставьте пустым — первый профиль автоматически станет наставником.

После входа откроются разделы наставника.

## Как подключить сотрудников

Есть два способа.

### Через интерфейс
**Сотрудники → + Добавить** → логин → имя → роль → код первого входа.

### Через Excel
**Контент → Импорт Excel** и загрузите файл со списком сотрудников. SkillHub автоматически создаст коды первого входа для новых людей и покажет их наставнику.

Сотрудник один раз вводит:

1. корпоративный логин;
2. код первого входа от наставника;
3. придумывает свой PIN.

Дальше он входит только по логину + PIN и не видит данные коллег.

## Как раздать одну ссылку группе

У наставника: меню профиля → **«Ссылка для сотрудников»**.

SkillHub сформирует ссылку, которая один раз передаст телефону адрес общей базы и публичный anon key. После открытия они сохраняются на устройстве.

Anon / publishable key не является секретным серверным ключом. Защита строк данных задаётся RLS-политиками в `schema.sql`. Никогда не используйте service_role key в приложении.

## Как загружать кейсы

В SkillHub:

**Контент → Импорт Excel → Скачать шаблон**.

- «Кейсы»: обычные и Hard-кейсы;
- «Диалоги»: карточки диалогов;
- «Шаги диалогов»: последовательные реплики клиента и варианты ответа;
- «Сотрудники»: массовое управление пользователями;
- «Назначения»: задания, дедлайны, адресаты и целевой %.

`draft` = только наставник.  
`published` = появляется у адресатов.  
`ALL` = всем сотрудникам.  
`Да` в «Уведомить» = создаётся внутреннее уведомление.

## На iPhone

Откройте HTTPS-ссылку GitHub Pages в Safari → **Поделиться → На экран «Домой» → Добавить**.

После этого появится иконка SkillHub.

## Что не является полностью готовым корпоративным слоем

Эта версия рассчитана на бесплатный пилот. Для промышленного банковского внедрения позже нужно заменить логин+PIN на корпоративный SSO и согласовать ИБ.

Внутренние уведомления и Realtime работают. Полноценный background Web Push при полностью закрытом приложении пока не включён: его лучше добавлять после того, как пилот и доступ без VPN подтверждены.
