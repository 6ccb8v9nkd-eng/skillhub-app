SkillHub 7.0 — Hierarchy & Access

Главные изменения:
1. Четыре роли:
   - Технический администратор SkillHub
   - Руководитель сектора (РС)
   - Руководитель группы
   - Сотрудник

2. Логин d.i.sharipova после миграции получает роль tech_admin.
   Тех. администратор видит все сектора, РС, руководителей и сотрудников и может сбрасывать доступ любому пользователю.

3. Прямая связь сотрудник → руководитель группы.
   Руководитель группы добавляет сотрудников вручную или Excel-импортом. Все строки, импортированные из его учетной записи, автоматически закрепляются за ним.

4. Первый вход:
   - Руководитель группы / РС: заранее разрешенный корпоративный логин → сразу придумать PIN. Код не нужен.
   - Сотрудник: корпоративный логин + код первого входа от руководителя группы → свой PIN.

5. Сброс доступа:
   - Сотруднику руководитель группы или тех. администратор выдает новый код.
   - Руководителю группы / РС тех. администратор сбрасывает доступ. После этого человек снова выбирает «Первый вход» и сам задает новый PIN. Временного пароля нет.

6. Excel-импорт пользователей:
   - Руководитель группы: все строки автоматически его команда.
   - РС: пользователи своего сектора.
   - Тех. администратор: все роли и сектора.

7. Excel-отчетность:
   - Параметры
   - Сводка
   - Динамика
   - Зоны развития
   - История ответов
   - Назначения
   В сводке дополнительно считаются выполненные, просроченные и текущие назначения.

8. Умная выдача тренировок сохранена:
   непройденные материалы первыми → после прохождения всех повторения без немедленного повтора последнего материала; в теме отображается «Пройдено X из Y».

Обновление существующего SkillHub 6.2/6.3:
1. Supabase → SQL Editor → выполнить SkillHub_7_0_MIGRATION.sql.
2. GitHub репозиторий skillhub-app → загрузить файлы из SkillHub_7_0_UPDATE.zip поверх текущих.
3. Подождать обновление GitHub Pages и перезагрузить SkillHub.

Контент, попытки, история ответов и назначения миграция не удаляет.
